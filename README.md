This project simulates an advanced **Smart Home IoT System** using **iFogSim**, integrating **edge computing, AI-driven automation, blockchain security, and hierarchical fog computing**. The system consists of multiple **smart zones**, each equipped with various IoT devices such as **sensors, actuators, control panels, and regional fog nodes** for efficient data processing and management.

**Key Features:**

1. **Multi-Zone Smart Home System:**
   - Includes distinct zones: **Living Room, Kitchen, Bedroom, Garage, and Outdoor Area**.
   - Each zone has **multiple sensors and actuators** to control smart home functions.
   
2. **Hierarchical Fog Computing:**
   - **Control Panels** act as **local fog nodes** managing device communications.
   - **Regional Fog Nodes** handle larger processing tasks for multiple houses.
   - **Cloud Backend** for heavy computation and data storage.

3. **AI-Driven Home Automation:**
   - AI algorithms optimize **energy usage, security detection, and smart scheduling**.
   - Examples include **occupancy-based lighting control and real-time anomaly detection**.

4. **Real-Time Data Analytics & Monitoring:**
   - Continuous data collection from **smart sensors**.
   - **Edge computing** enables real-time response to **security threats and energy optimizations**.

5. **Blockchain-Based Security:**
   - Implements **smart contracts for IoT device authentication**.
   - Ensures **tamper-proof transactions** for energy sharing and access control.

6. **Cybersecurity & Fault Tolerance:**
   - **Anomaly detection systems** prevent hacking attempts.
   - **Redundant fog nodes** ensure system resilience against failures.

7. **User Interaction & Smart Controls:**
   - **Voice-based home control** via AI Assistants (e.g., Alexa, Google Assistant).
   - **Mobile Dashboard** to track energy consumption, security alerts, and device status.

**Technical Implementation:**
- **Programming Language:** Java
- **Simulation Framework:** iFogSim
- **Networking:** MQTT, HTTP
- **Security:** Blockchain, Encryption
- **Data Processing:** AI & Edge Computing

**Applications:**
- **Smart Home Automation**
- **Energy Management & Optimization**
- **IoT Security & Cyber-Resilience**
- **Smart City & Community Automation**
